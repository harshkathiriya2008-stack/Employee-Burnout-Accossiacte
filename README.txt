# Employee Burnout Risk Assessment
A machine learning project that predicts an employee's Burn_Rate (burnout risk) using Linear Regression.

## How to run
1. pip install -r requirements.txt
2. Put your dataset file in a `Dataset` folder (`Dataset/train.csv`)
3. python project_1.py
4. (Optional) python chart.py for charts and EDA reports (Histogram, Scatter plot, Box plots, D-Tale, Sweetviz)
